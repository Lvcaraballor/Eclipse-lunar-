# El diagrama lunar de al-Biruni

Video explicativo en Remotion sobre el diagrama lunar atribuido a Abu Rayhan al-Biruni. La composición principal dura 26 segundos, está en formato 16:9 y recorre cinco escenas: apertura, contexto histórico, esquema orbital, fases lunares y fuente.

El esquema orbital es una visualización explicativa, no una reconstrucción del manuscrito ni un modelo a escala.

## Vista previa

Desde esta carpeta, ejecuta:

```bash
npm run dev
```

En Remotion Studio, selecciona `DiagramaLunarDeAlBiruni` para ver el video completo. Las cinco escenas también están registradas por separado para inspeccionarlas individualmente.

## Exportar

Para generar un MP4:

```bash
npx remotion render DiagramaLunarDeAlBiruni out/diagrama-lunar-al-biruni.mp4
```

## Fuente

Scott Christianson, *100 Diagrams That Changed the World*. El video presenta el diagrama como relacionado con *Kitab al-Tafhim* y conserva la atribución con cautela.
