# El diagrama lunar de al-Biruni

Video explicativo en Remotion sobre el diagrama lunar atribuido a Abu Rayhan al-Biruni. La composición principal dura 55,5 segundos, está en formato vertical 9:16 (1080×1920) y recorre cinco escenas: apertura, contexto histórico, esquema orbital, fases lunares y fuente. Conserva sin cambios la locución original de `public/locucion1.mp3`.

Los diagramas y el instrumento astronómico son recreaciones gráficas educativas; no son facsímiles del manuscrito ni reconstrucciones de objetos históricos. El esquema orbital no está a escala.

La escena de contexto incorpora el diagrama de fases lunares de `public/lunar-phases-al-biruni-reference.jpg`, identificado por Wikimedia Commons como una ilustración del manuscrito de *Kitab al-Tafhim*. La ficha lo marca como dominio público y cita su reproducción en Seyyed Hossein Nasr, *Islamic Science: An Illustrated Study* (1976): [ficha y metadatos](https://commons.wikimedia.org/wiki/File:Lunar_phases_al-Biruni.jpg).

## Vista previa

Desde esta carpeta, ejecuta:

```bash
npm run dev
```

En Remotion Studio, selecciona `DiagramaLunarDeAlBiruni` para ver el video completo. Las cinco escenas verticales también están registradas por separado para inspeccionarlas individualmente.

## Exportar

Para generar un MP4:

```bash
npx remotion render DiagramaLunarDeAlBiruni out/diagrama-lunar-al-biruni-vertical.mp4
```

## Fuente

Scott Christianson, *100 Diagrams That Changed the World*. El video presenta el diagrama como relacionado con *Kitab al-Tafhim* y conserva la atribución con cautela.
